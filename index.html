看见每一次敲击See every keystroke

Presscore 住在 macOS 菜单栏里，记下按键、点击、开机时长和每个应用的前台时间。在线默认关闭，关掉时不联网。窗口一关，画面全停。 Presscore lives in the macOS menu bar and counts keystrokes, clicks, screen time, and time in each app. Online is off unless you turn it on, and while it is off nothing goes online. Close the window and the drawing stops.

放在后台，几乎不耗电Almost no power in the background

窗口收进菜单栏之后，键盘预览、动画和界面刷新全部停下。只剩计数，每 5 秒批量写一次。实测关窗后一分钟大约只用 10 毫秒 CPU。Once the window is in the menu bar, the keyboard preview, animation, and interface updates all stop. Only counting remains, saving every 5 seconds. A measured minute with the window closed used about 10 milliseconds of CPU.

关掉窗口之后After you close it ≈ 0%

只数次数，不看内容Counts, never content

只记按了哪个键、按了几次，不记你打的字，也不上传按键顺序。在线默认关闭；关掉时数据只在这台 Mac。打开之后，也只上传你勾选的合计。统计键盘需要「输入监控」，由你自己打开。It records which key and how often, never what you type, and never the order of keys. Online is off unless you turn it on, and while it is off everything stays on this Mac. Turned on, it uploads only the totals you choose. Keyboard counting needs Input Monitoring, which you turn on yourself.

在线，由你打开Online, only if you want it

在设置里打开「在线」之后，才会检查更新，也才会和好友比较。关掉它，Presscore 不连接任何网络。分享的只有你勾选的合计，今天用了哪些应用也可以只挑几个。Turn on Online in Settings and Presscore can check for updates and compare with friends. Turn it off and it makes no network connections. Only the totals you choose are shared, and you can pick which of today’s apps to include.
